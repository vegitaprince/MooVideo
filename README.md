# MooVideo 0.6.3

MooView 이미지 뷰어의 간결한 버튼과 하단 조작부를 바탕으로 만든 Windows 동영상 뷰어입니다.

[Windows x64 포터블 ZIP 다운로드](https://github.com/vegitaprince/MooVideo/releases/download/v0.6.3/MooVideo-0.6.3-win-x64.zip)

ZIP 전체를 풀고 `App/MooVideo.exe`를 실행하세요.

## 0.6.3 변경 사항

- 텍스트를 넣을 때 글자 크기를 픽셀 단위로 선택할 수 있습니다. 이미 넣은 텍스트는 선택한 뒤 오른쪽 아래 모서리를 드래그하거나 도구 모음의 숫자 버튼으로 크기를 바꿀 수 있습니다. Ctrl+Z로 크기 변경을 되돌릴 수 있습니다.
- 그림 색상 창에서 **스포이드**를 누른 뒤 영상의 원하는 지점을 클릭하면 해당 픽셀의 색을 가져옵니다. Esc로 취소할 수 있습니다.
- 영상 오른쪽에서 휠을 위로 돌리면 이전 프레임, 아래로 돌리면 다음 프레임으로 이동합니다. 빠르게 돌릴 때도 같은 방향으로 탐색합니다.

## 0.6.2 변경 사항

- 그림 도구의 굵기 메뉴 전체에 검은색 배경을 적용해 흰색 견본 선이 잘 보이도록 수정했습니다.

## 0.6.1 변경 사항

- 업데이트를 다운로드하고 검증하는 동안에도 영상을 재생하고 조작할 수 있습니다. 설치 준비가 끝나면 팝업이 열리고, **설치 및 재시작**을 누를 때만 앱을 닫고 적용합니다.
- **나중에**를 눌러 계속 시청할 수 있습니다. 같은 실행 중에는 **업데이트 확인**에서 준비된 업데이트를 다시 열 수 있습니다.

## 0.6.0 변경 사항

- 그림 비우기가 화면에 즉시 반영됩니다. Ctrl+Z 또는 실행 취소 버튼으로 획, 지우기, 화살표, 텍스트 추가·이동, 비우기를 되돌릴 수 있습니다.
- 색상 버튼은 현재 색을 원으로 표시합니다. 색상환에서 색을 고르고 밝기 슬라이더로 조절할 수 있습니다.
- 굵기 버튼과 메뉴는 선으로 굵기를 표시합니다. 펜과 지우개 굵기는 각자 저장되고 다음 실행에도 복원됩니다.
- T 버튼을 누른 뒤 영상에서 클릭해 텍스트를 추가하세요. 텍스트 도구가 선택된 상태에서 글 상자를 끌어 이동할 수 있습니다.
- 화살표 버튼을 누른 뒤 영상에서 시작점부터 끝점까지 드래그하세요. 텍스트와 화살표는 PNG 저장과 클립보드 복사에 포함됩니다.

## 화면과 조작

- 영상에는 테두리가 없습니다. 포인터를 뷰어 안에 올리면 영상 위에 반투명한 제목 영역과 하단 조작부가 나타납니다. 버튼 아이콘은 흰색 계열이며, 포인터가 뷰어를 벗어나면 조작부가 숨겨집니다.
- 전체화면에서는 상단 제목 영역이 숨겨지고, 마우스를 움직이는 동안 하단 조작부가 나타납니다. 움직임을 멈추면 잠시 후 숨겨지며, 조작부나 열린 패널 위에 포인터가 있으면 유지됩니다.
- 화면의 빈 곳을 끌어 창을 이동하고, 모서리를 끌어 크기를 조절할 수 있습니다. 영상 우클릭 메뉴 또는 Ctrl+0으로 영상 원본 크기에 맞춰 창을 조절합니다.
- 하단 목록 버튼은 오른쪽 재생목록을, 폴더 버튼은 오른쪽 파일 탐색기를 엽니다. 다시 누르면 닫힙니다.
- 파일 탐색 패널은 Windows의 Explorer Browser를 사용합니다. 상위 폴더 이동, 직접 경로 입력, 경로 옆 폴더 트리, 썸네일 크기 조절을 지원합니다. 파일 목록과 썸네일은 Windows가 표시하며 앱에서 FFmpeg로 별도 썸네일을 만들지 않습니다. 내부 파일 목록의 색상과 모양은 현재 Windows 테마를 따릅니다.
- 파일을 화면 위 1/3에 놓으면 재생목록에만 추가됩니다. 중·하단에 놓으면 즉시 재생합니다. 여러 파일과 폴더를 받을 수 있습니다.
- 활성 뷰어의 왼쪽 절반에서 휠을 돌리면 볼륨이 바뀌고, 오른쪽 절반에서는 앞뒤 프레임을 탐색합니다. 빠르게 돌리면 최대 16배 상당의 가속 탐색을 합니다. 스크롤을 멈추면 이전에 재생 중이던 영상은 다시 재생되고, 일시정지 상태였던 영상은 그대로 멈춰 있습니다. 휠 클릭은 전체화면을 토글합니다.
- 오른쪽 패널에서는 휠이 해당 패널 스크롤과 입력 조작에 사용됩니다.
- 파일 탐색기의 영상을 더블클릭하면 MooVideo에서 재생합니다. 재생목록에서는 우클릭으로 순서 변경·제거가 가능하며 실제 파일은 삭제하지 않습니다.
- 재생목록의 더보기 버튼에서 M3U/M3U8 불러오기, 저장, 비우기를 지원합니다.
- 영상은 더블클릭으로 재생·일시정지합니다. 우클릭 메뉴에서 맞춤·채우기·원본 크기 창, 항상 위, 전체화면, 앱 종료를 선택합니다. 볼륨 아이콘에 포인터를 올리면 세로 슬라이더가 나타나며, 드래그하거나 방향키로 조절할 수 있습니다.
- 재생 위치, 음량, 재생목록, 최근 탐색 폴더를 로컬에 기억합니다. 데이터 위치: `%LOCALAPPDATA%/MooVideo`.

## 업데이트와 기본 앱

- 앱을 실행할 때마다 [GitHub Releases](https://github.com/vegitaprince/MooVideo/releases)의 새 안정 버전을 확인합니다. 새 버전은 백그라운드에서 다운로드하고 SHA-256 해시를 검증합니다. 설치 준비가 끝나면 **설치 및 재시작** 또는 **나중에**를 선택할 수 있습니다. 영상 우클릭 메뉴나 정보 패널의 **업데이트 확인** 버튼으로도 열 수 있습니다.
- 설치하는 동안 App 폴더를 옮기지 마세요. 앱 폴더에 쓰기 권한이 필요합니다.
- 영상 우클릭 메뉴나 정보 패널의 **영상 기본 앱 설정**을 누르면 현재 MooVideo 실행 경로를 Windows에 등록하고, MooVideo의 기본 앱 설정 화면을 엽니다. MP4/MOV/MKV 등 원하는 확장자를 Windows에서 선택하세요. 기존 기본 앱을 앱이 강제로 변경하지 않습니다. 앱 폴더를 옮긴 뒤에는 다시 등록해야 합니다.
- HAP·Notch는 코덱이므로 별도의 파일 확장자가 아닙니다. Windows 탐색기에 해당 영상의 썸네일이 없으면 파일 아이콘이 보일 수 있지만 MooVideo 재생 지원에는 영향이 없습니다.

## 무손실 편집

하단 가위 버튼 또는 **E**를 누르세요.

1. **구간 추출**: 시작과 끝을 입력하거나 재생바의 두 마커를 끌어서 범위를 정합니다. 표시된 실제 키프레임 위치를 확인한 뒤 새 파일로 저장합니다.
2. **둘로 분할**: 지정한 키프레임에서 `_01`, `_02` 파일 두 개로 나눕니다.
3. **오디오 제거**: 모든 오디오 트랙을 제거하고 다른 스트림을 복사합니다.
4. **오디오 교체**: 기존 오디오를 모두 제거하고 선택한 파일의 첫 번째 오디오 트랙을 복사합니다.
5. **오디오 추가**: 기존 트랙을 유지하고 선택한 파일의 첫 번째 오디오 트랙을 별도로 추가합니다.

원본·기존 파일은 덮어쓰지 않습니다. 저장에 성공한 결과만 최종 파일 이름으로 옮기며, 취소·실패한 임시 파일은 정리합니다. 진행 중에는 패널 변경과 앱 종료를 막아 결과가 유실되지 않도록 합니다.

### 정확도와 제약

- H.264/HEVC 등 프레임 간 압축 영상의 무손실 컷은 키프레임 제약이 있습니다. 입력한 시작·끝은 이전 키프레임으로 맞추며, 영상 끝은 끝까지 유지합니다. 원하는 임의 프레임에서 정확하게 자르려면 재인코딩이 필요합니다. 이 버전은 자동 재인코딩하지 않습니다.
- 구간 추출은 키프레임 분할 후 해당 구간을 가져오므로 **원본 파일 크기 정도의 추가 임시 공간**이 필요합니다. 대용량 파일은 키프레임 분석과 복사에 시간이 걸립니다.
- 오디오 패킷 경계 때문에 트랙 시작과 끝이 소폭 달라질 수 있습니다. 기존 챕터의 구간별 재편집은 제공하지 않습니다.
- 오디오 추가는 믹싱이 아닙니다. 여러 트랙 중 선택하여 재생하며 길이가 다른 오디오를 자동으로 늘리거나 반복하지 않습니다.
- 오디오 코덱과 MP4/MOV 컨테이너가 호환되지 않으면 설명과 함께 중단합니다. 필요하면 저장 형식으로 MKV를 선택할 수 있습니다.
- 전원 종료 등으로 강제 중단된 경우 저장 폴더의 `.moovideo-*` 임시 폴더가 남을 수 있습니다.

## 지원과 검증

libmpv/FFmpeg 디코더로 H.264, HEVC, AV1, VP9, ProRes, DNxHD, MPEG 계열, HAP, HAP Q, NotchLC 등 다양한 코덱을 재생합니다. MP4/MOV/MKV/AVI/WebM/MXF 등 컨테이너를 지원합니다. 별도 코덱 팩을 설치하지 않습니다.

실제 샘플 재생 검증: H.264, HEVC, AV1, ProRes, HAP, HAP Q, NotchLC alpha-ramp 및 chroma-alpha. 모든 코덱 프로파일·해상도·GPU에서의 실시간 성능을 보장하지는 않습니다. 특히 HAP·NotchLC는 해상도와 장치 성능에 영향을 받으며 전용 GPU 텍스처 재생 경로가 아닙니다.

영상 패킷 해시 비교로 구간 추출·분할·오디오 작업이 영상 데이터를 재인코딩하지 않음을 검증했습니다. 오디오 교체 데이터도 동일성을 비교했습니다. 상세 결과는 `Verification` 폴더에 있습니다.

자막 SRT/ASS/SSA/VTT와 내장 자막·오디오 트랙 선택, 자막 타이밍 조절, 배속, 반복, PNG 프레임 저장을 포함합니다. URL 스트리밍·DVD 메뉴·고급 컬러 관리 설정은 이 버전의 UI에 포함하지 않았습니다.

## 주요 단축키

| 키 | 기능 |
|---|---|
| Ctrl+O | 파일 열기 |
| Ctrl+Shift+O | 폴더 선택 |
| Space | 재생 / 일시정지 |
| ← / → | 5초 이동, Shift와 함께 10초 |
| Ctrl+← / Ctrl+→ | 이전 / 다음 파일 |
| , / . | 이전 / 다음 프레임, 일시정지 유지 |
| ↑ / ↓ / M | 음량 5% 증가 / 감소 / 음소거. Shift와 함께 10% |
| F11, F 또는 휠 클릭 | 전체화면 |
| Ctrl+0 | 영상 원본 크기에 맞춰 창 조절 |
| Esc | 전체화면 또는 오른쪽 패널 닫기 |
| P / E / I | 목록 / 편집 / 정보 |
| S | 현재 프레임 PNG 저장 |
| [ / ] | 구간 시작 / 끝 표시 |
